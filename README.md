# 主日聚會情況分析 Dashboard v2

## 這一版新增
- 台北市召會目前週次：第一季 1–4 月、第二季 5–8 月、第三季 9–12 月。
- 可選最近 4 / 8 / 12 個有效主日週次。
- 初信：以分析截止日為基準，受浸日期在最近 104 週內者。
- 人員明細顯示「受浸日期」「初信」，並可篩選初信／非初信／日期不明。
- 大區比較新增初信人數。

## 使用方式
1. 用 VS Code 開啟本資料夾。
2. 在 `index.html` 上按右鍵 → Open with Live Server。
3. 按「選擇 Excel」匯入系統匯出的 `.xls` 或 `.xlsx`。
4. 選擇年份、目前週次與最近 4 / 8 / 12 週。

## 初信欄位
程式會尋找 Excel 的 `受浸日期`、`受浸日` 或 `受浸` 欄位。
以所選分析區間的截止日往前 104 週內受浸者判定為「初信」；受浸日期超過 104 週者為「非初信」；沒有受浸日期者列為「日期不明」。

## 隱私
Excel 只在瀏覽器記憶體讀取，本程式沒有上傳 API，也不使用 localStorage / IndexedDB。
重新整理、關閉頁面或按「清除本次資料」後，本次資料即不由本工具保存。


## v2.3 分析區間

- 不提供年份或季度篩選。
- 「目前」以匯入 Excel 中最新一個已發生的主日日期為準。
- 可切換最近 4、8、12 週；直接由最新日期往前取相對應週次，即使跨月、跨季、跨年也不中斷。
- 初信仍以分析截止日往前 104 週內的受浸日期判斷。

## v2.4 更新
- 「羣組」改為複選勾選。
- 快速組合：大專＋青職、青少年（國中＋高中）、學生專項（大專／大學＋國中＋高中）、兒童（國小）。
- 支援資料欄位使用「大專」或「大學」兩種名稱。
- 多選採 OR 邏輯：勾選多個羣組時，顯示屬於任一所選羣組的人員。


## v2.5 聚會情況規則
- 觀察區間：最近 6／8／10／12／16 週。
- 週週聚會：固定看最近 12 週，12 週皆有聚會。
- 常聚會：所選觀察區間內平均至少每 3 週一次，且最近一次聚會距今不超過 3 週。
- 偶聚會：未達常聚會，平均至少每 4 週一次，且最近一次聚會距今不超過 4 週。
- 零星聚會：未達偶聚會，但最近 8 週內至少仍有聚會。
- 近期未聚會：最近一次聚會距今超過 8 週，或全期間沒有聚會紀錄。


## v2.6 更新
- 人員明細新增「最近一次聚會日期」欄位。
- 日期取自整份匯入資料中該人最後一次有聚會紀錄的主日。
- 若無任何聚會紀錄則顯示「—」。
